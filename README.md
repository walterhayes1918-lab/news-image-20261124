## What is in this repo

- `main.py` — the entry program. Python 3.13, standard library only
  (`os` and `shutil`). It copies `entry.png` to `$MAKEFUN_OUTPUT_DIR`
  or `/output/entry.png`, byte for byte. No network, no clock, no
  randomness, nothing to install, so two runs always produce identical
  bytes.
- `entry.png` — the image itself: a 1024×1024 newspaper front page,
  "THE WORLD IN ONE PAGE", for Tuesday 24 November 2026, 126,395 bytes.
- `LICENSE` — MIT.
